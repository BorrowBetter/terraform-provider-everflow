# AGENTS.md

## Workflow

All non-trivial work follows this pipeline:

1. **Explore** — investigate the codebase and relevant context before planning.
2. **Plan** — produce an explicit implementation plan; get approval before coding.
3. **Implement** — execute the approved plan.
4. **Staff Eng Review** — a staff-engineer-level review pass on the implementation.
5. **PR** — open the pull request.
